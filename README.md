# YouTube Premium RU for Shadowrocket

Оптимизированный модуль Shadowrocket для фильтрации рекламы YouTube, PiP и фонового воспроизведения.

## Установка

1. Загрузите файл `YT-Premium-V1-RU-Optimized.module` в корень публичного GitHub-репозитория.
2. В Shadowrocket откройте добавление удалённого модуля и вставьте прямую ссылку на Raw-файл:

   `https://raw.githubusercontent.com/<ваш-логин>/<имя-репозитория>/main/YT-Premium-V1-RU-Optimized.module`

3. Для фильтрации HTTPS-ответов включите HTTPS-дешифровку Shadowrocket и установите/доверяйте его сертификату.

## Параметры

Параметры меняются в редакторе аргументов модуля Shadowrocket: блокировка загрузок и immersive-вкладок включены; Shorts не блокируются; субтитры и тексты песен по умолчанию не переводятся.

## Примечания

- Модуль блокирует QUIC/UDP для доменов YouTube, чтобы трафик проходил через фильтры HTTPS.
- Скрипт ответа загружается с upstream-проекта Maasea и может обновляться независимо от этого репозитория.
- Гарантировать работу на всех версиях YouTube/Shadowrocket нельзя: YouTube регулярно меняет API.
